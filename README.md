# DCPA Website

Official website for DCPA (Davidson County Public Academy), hosted via GitHub Pages.

## Project Overview

This is a static website built with HTML, CSS, and JavaScript. It serves as the primary online presence for the academy, providing information about academics, admissions, student life, and more.

## Website Structure

The site consists of the following main pages:

- **index.html** - Home page
- **about.html** - Information about DCPA
- **academics.html** - Academic programs and curriculum
- **admissions.html** - Admissions information and requirements
- **apply.html** - Online application portal
- **student-life.html** - Student activities and campus life
- **parents.html** - Resources for parents
- **success.html** - Student success stories and testimonials

## Files & Assets

- **global.css** - Main stylesheet for consistent styling across all pages
- **menu.js** - Navigation menu functionality and interactions
- **README.md** - This file

## Local Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/cmcgee121906/dcpa.github.io.git
   cd dcpa.github.io
   ```

2. Open any HTML file in your web browser, or use a local server:
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   ```

3. Visit `http://localhost:8000` in your browser

## Deployment

This site is automatically deployed to GitHub Pages using the `main` branch. Any changes pushed to `main` will be live within a few minutes.

To push changes:
```bash
git add .
git commit -m "Your commit message"
git push origin main
```
